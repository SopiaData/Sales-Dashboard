# Sales-Dashboard

Power Query: Imported and cleaned raw sales, product, and calendar data.

Power Pivot: Built a relational data model with calculated columns and relationships.

DAX: Created custom KPIs such as Total Sales and Profit using calculated logic.

PivotTables & PivotCharts: Visualized monthly and regional performance.

Slicers & Timeline: Enabled dynamic filtering by product category, region, and date.

Conditional Formatting: Highlighted high/low performing months at a glance.
